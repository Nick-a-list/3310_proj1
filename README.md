# 3310_proj1<br />
Fundamental Algorithms:<br />

Sorting Algorithms<br />
Tower of Hanoi<br />
Matrix Multiplication<br />

<br />
How to use: Download files into IDE, download any necessary libraries, start the program.<br />
Type Sorting, Tower, or Matrix to Proceed with the testing of the algorithms. Type End to exit.<br />

<br />FILES INCLUDED:<br />
- main.py (driver program)<br />
- sorting_algorithms.py (Contains Merge Sort and Quick Sort algorithms)<br />
- tower_hanoi.py (Contains the Tower of Hanoi algorithm)<br />
- matrix_multiplication.py (Contains Classical and Strassen's Matrix Multiplication)<br />
- Report.pdf<br /><br />

REQUIREMENTS:<br />
- Python 3.x<br />
- libraries: numpy, matplotlib<br />

HOW TO RUN:<br />
1. Ensure all .py files are in the same directory.<br />
2. Open your terminal.<br />
3. Install the required libraries<br />
4. Run the main file using the command:
   python main.py<br />
5. An interactive menu will appear. Type "Sorting", "Tower", or "Matrix" to run the benchmarks. Type End to exit from this prompt. <br />
6. The program will output timing progress to the console and automatically generate a pop-up graph when finished. Close the graph window to return to the main menu. <br />
